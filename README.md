
**QA-Automation-Guvi-EdTech-Platform**
>Selenium Pytest automation framework using POM architecture with explicit waits, exception handling, reporting and CI/CD integration.

**Project Title**
>Automation Testing of Edtech Platform Web application https://www.guvi.in

**Overview**
>This Project automates critical GUVI website functionalities using selenium WebDriver and Pytest framework following
the Page object model (POM) design pattern

**Features**
* Selenium WebDriver automation
* Pytest Framework
* Page Object Model(POM) 
* Explicit Waits
* Exception Handling
* Dynamic element Handling
* Pytest HTML Reports
* Reusable BasePage methods
* Github Actions CI/CD integration

**Tech Stack**
* Python
* Selenium
* Pytest
* Pytest HTML
* Github Actions

**Test Scenarios Covered**
* Login Button Validation
* Signup Buton Validation
* Menu Navigation Validation
* Courses menu validation
* Practice menu validation
* Dynamic Chatbox validation
* valid login test 
* Invalid login test
* Logout functionality

**Framework Design**
* Page Object Model
* Reusable BasePage utilities
* Explicit wait strategy
* Dynamic element handling
* Exception handling

**Installation**
> git clone <url>
> CD Project1
> pip install -r requirements.txt

**Run Tests**
>pytest

**Generate HTML Report**
> pytest --html=reports/report.html --self-contained-html

**CI/CD**
**Github Actions pipeline automatically**
* Install dependencies
* Runs test suite
* generate reports

**Challenges Solved**
* Dynamic Dropdown
* Hidden Element Section
* Synchronization issues
* Javascript click fallback 
* Dynamic chatbox rendering
* Explicit wait optimization
